# Bildprompts

1. wissenschaftliche Szenenaussage exakt bestimmen
2. Hauptmotiv und benötigte unterstützende Elemente definieren
3. passende Fachgebietsregel aus `SCIENCE-VISUAL-GRAMMAR.md` anwenden
4. Master-Stilblock `Cinematic Scientific 3D Editorial` anhängen
5. sichtbare Schrift, Labels, Formeln, Logos und UI im generierten Bild verbieten
6. Prompt unter `02-bilder/prompts/` speichern
7. finales Bild unter `02-bilder/images/<szene>/` ablegen

Jedes Bild erklärt genau eine Aussage und muss ohne Remotion-Bewegung funktionieren.
