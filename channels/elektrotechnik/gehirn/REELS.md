# Reels

Jeder Reel wird exakt so abgelegt:

```text
reels/YYYY-MM-DD_bis_YYYY-MM-DD/NN_Thema/
├── 01-script-audio/
├── 02-bilder/
├── 03-caption/
├── 04-pdf/
├── 05-export/
├── 06-projektdateien/
└── README.md
```

Die Nummer `NN` ist der Produktionsslot innerhalb der Woche. Es gibt keinen zusätzlichen Wochentagsordner.
