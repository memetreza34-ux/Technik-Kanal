# Science Image Prompt Template

Jeder Szenenprompt folgt demselben Grundvertrag.

## 1. Wissenschaftliche Aussage

```text
The viewer must immediately understand exactly one scientific statement: [GENAUE FACHLICHE AUSSAGE].
```

## 2. Hauptmotiv

```text
Show one dominant scientific subject: [HAUPTMOTIV].
Use only the supporting elements that are necessary to understand this one statement.
Do not introduce a second competing concept.
```

## 3. Bildwelt

```text
Cinematic Scientific 3D Editorial.
High-end stylized scientific 3D illustration, scientifically plausible, realistic materials and believable proportions, modern adult editorial look, clear spatial depth, controlled lighting and strong mobile readability.
```

## 4. Farbsemantik

Nur fachlich sinnvolle Akzente verwenden:

- Cyan/Blau: Energie, Strom, Signal
- Gold: Erklärung/Fokus
- Orange: Wärme
- Rot: Gefahr/kritischer Zustand
- Violett: Felder, Plasma oder kosmische Prozesse, wenn passend
- natürliche Stofffarben für Chemie, Materialien, Planeten, Flüssigkeiten und reale Objekte

## 5. Textfreie Basisbilder

Jeder Prompt muss ausdrücklich enthalten:

```text
No visible text, labels, letters, numbers, formulas, units, logos, watermark or fake type plate.
```

Es gibt keine Ausnahme für KI-generierte Labels. Alle Begriffe, Werte und Formeln werden später kontrolliert und statisch gesetzt.

## 6. Layout

```text
Vertical 9:16, full-bleed edge-to-edge.
Keep the upper 18 percent visually calm for optional controlled title text.
Keep the lower 25 percent calm for subtitles.
Make the main subject large and dominant.
No white or gray bars, no letterboxing, no split background and no visible seam.
```

## 7. Keine Motion-Cues

Das Bild muss vollständig als Standbild funktionieren.

```text
Do not design the scene around camera movement, zoom, pan, parallax, animated particles, animated arrows or any later motion effect.
The final still image must communicate the idea without animation.
```

## 8. Cover / Bild 01

Bild 01 ist zugleich erste Szene und Cover-Hintergrund.

Für Bild 01:

- drei unterschiedliche Kompositionsvarianten erzeugen
- alle drei zeigen dieselbe zentrale Frage
- dieselbe Scientific-3D-Bildwelt verwenden
- keinen separaten Thumbnail-Stil erzeugen
- genau einen Gewinner auswählen

## Negativprompt

```text
Pixar, clay, childish cartoon, generic schoolbook diagram, fake science, impossible physics, wrong wiring, fantasy machinery, visible text, labels, letters, numbers, formulas, logos, watermark, UI dashboard, overcrowded schematic, tiny central subject, white border, gray strip, letterboxing, split background, visible seam, decorative icons, unnecessary arrows, motion blur, cinematic camera movement cue
```
