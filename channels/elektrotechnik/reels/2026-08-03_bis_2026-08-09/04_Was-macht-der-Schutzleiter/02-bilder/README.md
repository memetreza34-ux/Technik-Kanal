# Bilder

Für diesen Reel werden keine KI- oder Nutzerbilder benötigt.

Alle neun Szenen entstehen direkt in Remotion. Dieser Ordner bleibt nur wegen des gemeinsamen FinanzNeo-kompatiblen Projektvertrags und für optionale öffentliche Medien bestehen.

Öffentliche Bilder werden nicht manuell hier zusammengesucht. Sie werden über `02-public-media/public-assets.json` dokumentiert und mit `npm run electrical:public-media -- "<reel-ordner>"` in den passenden Szenenordner kopiert.
