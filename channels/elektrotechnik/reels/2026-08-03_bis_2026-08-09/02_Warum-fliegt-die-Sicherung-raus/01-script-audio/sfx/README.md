# SFX-Ablage

Lege optionale Soundeffekte als WAV-Dateien in diesen Ordner. Die erwarteten Dateinamen stehen in `../../06-projektdateien/sfx-events.json`.

Empfohlen: 48 kHz, trocken, ohne Musik oder Hall.

Vorhandene Dateien werden automatisch an die festgelegten Wörter oder Szenenpositionen gekoppelt. Fehlende SFX erzeugen nur eine Warnung und verhindern den Render nicht.
